# 骸轨（主线：平川地铁 · 中央枢纽）

> **这个作品在本仓库的定位是「平台 MVP」**：目的不是做成完整商业作品，而是**把 AI 全链路跑通**——
> 图 → 视频 → 3D → 游戏 → 量化验收 → 试玩录像，每一环都有工具、有测试、可复现。
> 范围就三件：**1 个主角、1 个 3D 场景（含部分素材）、一局 3–5 分钟**。
> 下一部才是正式作品（第三人称动作游戏），本作的价值在于把工具链和纪律先跑顺。

一局 3–5 分钟的「另类跑酷 + 探索」。你是一条活在地铁里的环节蠕虫，从平川地铁东入口沿主轨道往西，
穿过满是残骸的站台、断轨与竖井，抵达中央枢纽站地下的球形舱室——那里有一小块淡蓝色的光，睡了五十年。

- **世界来源**：小说《废土中的正义》第二十五章《地下铁》、第三十五章《平川地铁东》、第三十七章《导弹蜈蚣》。
- **玩法动词**：贴壁爬行 + 蓄力弹射（原作设定：变异蠕虫用铲子头挖洞，把石子以极高速度喷出去）。
- **主角为什么是虫**：环节体用样条跟随就能做出极好的运动，**不需要骨骼绑定**——正好绕开我们目前最弱的一环。
- **成本**：0（全部素材由本机 ComfyUI 生成）。
- **规格**：见 [SPEC.md](SPEC.md)；视频提示词见 [video-prompts.md](video-prompts.md)。

## 怎么跑

```powershell
cd <仓库根目录>
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/games/pingchuan-rail/game/index.html
```

操作：`← →` 爬行 · `↑ ↓` 爬墙 · `空格` 按住蓄力、松开弹射 · `R` 重来。
参数：`?autostart` 跳过标题、`?seed=N` 固定残骸排布。
**第一次按键后才有声音**（浏览器策略）：底层是 30 秒 drone 循环 + 灯管嗡鸣，
弹射、粉尘落地、火花、扫描各有一条音效。

## 自动化验收（不需要 GPU）

```powershell
node tests\smoke_game.mjs          # 起服务 + Chrome 按键：爬行/弹射/落地/9 个路口/结局/帧率/模型加载
node tests\capture_spots.mjs       # 三个固定位置截图（并排图素材）
python tests\check_repo.py         # 静态检查：结构、链接、语法、必需文件与工作流、体积
```
