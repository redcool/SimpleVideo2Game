# 骸轨（主线：平川地铁 · 中央枢纽）

一局 3–5 分钟的"另类跑酷 + 探索"。你是一条活在地铁里的环节蠕虫，从平川地铁东入口沿主轨道往西，
穿过满是残骸的站台、断轨与竖井，抵达中央枢纽站地下的球形舱室——那里有一小块淡蓝色的光，睡了五十年。

- **世界来源**：小说《废土中的正义》第二十五章《地下铁》、第三十五章《平川地铁东》、第三十七章《导弹蜈蚣》。
- **玩法动词**：贴壁爬行 + 蓄力弹射（原作设定：变异蠕虫用铲子头挖洞，把石子以极高速度喷出去）。
- **主角为什么是虫**：环节体用样条跟随就能做出极好的运动，**不需要骨骼绑定**——正好绕开我们目前最弱的一环；
  也符合"另类跑酷"的原始想法。
- **成本**：0（全部素材由本机 ComfyUI 生成）。
- **规格**：见 [SPEC.md](SPEC.md)；视频提示词见 [video-prompts.md](video-prompts.md)。

## 怎么跑

```powershell
cd <仓库根目录>
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/games/pingchuan-rail/game/index.html
```

操作：`← →` 爬行 · `↑ ↓` 爬墙 · `空格` 按住蓄力、松开弹射 · `R` 重来。
参数：`?autostart` 跳过标题、`?seed=N` 固定残骸排布。

自动化验收（不需要 GPU）：

```powershell
node tests\smoke_game.mjs
```

状态：**原型已可玩 + 第一批素材已出**（3 张锚点图 + 3 条音效）。
预览图在 `look/`（原图与音频在 `assets/`，不入库）；指标与耗时见 `SPEC.md` 第 8 节。
还缺：残骸 3D、4 张平铺贴图、3 条音效 + 音乐、5 条参考视频、三张并排图。
