## 三条严重问题（均已修）

### 1. 扫描锥永不触发 —— 唯一的压力源是死代码

- 证据：`Math.abs(toWorm.angle() + Math.PI/2 + angle) < halfAngle*0.85`；
  而 three r160 的 `Vector2.angle()` 是 `atan2(-y,-x) + π`，值域 **[0, 2π)**，
  代入后最小值 0.95 > 阈值 0.527 → `inside` **恒为 false**。
- 更糟：我刚往标题卡写了「躲开那束光」——教学文案在教一个不存在的机制。
- 修法：显式 `atan2` 求角差并绕回 (−π, π]；视觉半角与判定半角统一（`coneHalfAngle`）；
  新增 `debug.pinScanner(0)` 与断言「站进锥内 4 秒必须 deaths +1」。

### 2. 蓄力时滑行被放大 4 倍（实测 21.8 m/s）

- 证据：`carried = slideSpeed / speed`，而 `speed` 在蓄力时 ×0.25 → 除出 4 倍。
- 修法：改用不随蓄力缩放的 `baseSpeed` 归一。

### 3. 落金属的"惯性滑行"没实现，`state.speed` 还会撒谎

- 证据：落地把速度写进 `velocity`，但贴面移动只读 `slideSpeed`；`state.speed` 取 `velocity.length()`。
  实测落钢轨 `speed=13.697` 而角色纹丝不动。
- 修法：落地写 `slideSpeed` 并清零 `velocity`；`state.speed` 贴面时返回 `slideSpeed`。

### 4. 落地判定：`<= 0` 与严格异号都错，正解是"最小法向速度"

- `<= 0`：端点共面时每帧脱离又落回（站台末端 x 钉在 96.00）；
- `< 0`（照审核建议直改）：走离边缘后同高度落点再也接不上，连续通关立刻 37 次死亡；
- **正解**：保留 `<= 0`，另加「必须 ≥0.5 m/s 迎面速度」——站桩零速不会被判成撞击，
  走离边缘仍会自然坠落（这正是我们要的），跳跃也能正常落地。
