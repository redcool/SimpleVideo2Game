# 写"样子规格"（Look Spec）的模板

动手之前先写这一页。**每一行都要能被测量或至少能被指出位置**，形容词不算。

## 模板

```markdown
# Look Spec — <项目/关卡名>

## 参考
- 参考素材：<文件>，用于对比的固定点：<秒, 秒, 秒>
- 参考的主色（palette_report.py 输出）：#RRGGBB(占比) ×5
- 参考区间：mean_saturation=…，contrast=…，edge_density=…

## 光与色
- 天空：<hex>      地平线雾：<hex>      地面：<hex>      主体强调色：<hex>
- 主光方向/色温：<方位>，<色温 K 或 hex>
- 环境光（半球光上下）：<hex>/<hex>，强度 <0–3>
- 曝光：toneMapping=<ACES/AgX/Linear>，exposure=<0.8–1.4>

## 大气与后处理
- 雾：<Fog/FogExp2>，near <数值>，far <数值>，颜色 <hex>
- Bloom：强度 <0–1>，半径 <0–1>，阈值 <0–1>（只给光源，不给全画面）
- 色调曲线/分级：lift <三通道>，gain <三通道>，阴影偏 <色相>
- 暗角：<0–0.6>，起点 <0–1>      颗粒：<0–0.1>，尺寸 <px>
- 其他：<景深/色差/暗角>，只在参考里有的时候加

## 机位（可量化）
- 视角：第三人称背后 / 侧视 / 俯视；距主体 <主体身高倍数>，高度 <倍数>，俯角 <度>
- 镜头：等效 <mm>，或 FOV <度>
- 跟随：阻尼 k=<数值>（1-exp(-k·dt)），前瞻 <米>，跳跃时高度滞后 <米>

## 主体可读性
- 主体在画面中的高度占比目标：<8–25%>
- 主体与背景的分离手段：<色相/明度/轮廓光/景深>，目标亮度差 ≥ <25>
- 主体最小可辨尺寸（缩略图尺度）：<px>

## 关键瞬间
- 位置：<秒>  画面中心内容：<一句话>
- 需要哪些反馈：<粒子/光/音>，持续 <秒>

## 验收
- [ ] 三个固定点都有并排图，缩略图大小下能认出是同一个世界
- [ ] palette_report 与 frame_metrics 全部在区间内（或写了偏离理由）
- [ ] 主体在缩略图尺度可辨
- [ ] 0 控制台错误，帧率达标
```

## 三条纪律

1. **先量参考再写数值**，不要凭印象填 hex。用 `palette_report.py 参考素材`。
2. **规格是活的，但改动要留痕**：改数值时写一句"因为对比图 X 显示……"。
3. **不许写不可测量的词**当作验收条件：`cinematic`、`高级感`、`有氛围` 只能出现在备注里。
