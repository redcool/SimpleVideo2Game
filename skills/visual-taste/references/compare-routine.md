# 并排对比流程（Compare Routine）

## 一、固定三个点

| 位置 | 选它的理由 | 怎么取 |
|---|---|---|
| 起点 | 玩家最先看到、最容易被劝退 | 视频第 0.5–2 秒；游戏开局同一处 |
| 关键瞬间 | 这段视频卖的就是它 | 视频里最"贵"的 1–2 秒；游戏里对应机制触发时 |
| 远处 | 暴露世界边界、雾、密度问题 | 视频最后 1–2 秒；游戏里往前走一段后回头 |

**永远这三个点。** 换点比等于用运气冒充进步。

## 二、每轮的命令

```powershell
# 参考视频 vs 游戏录像（同一时间轴）
python skills\visual-taste\scripts\side_by_side.py 参考.mp4 录像.mp4 -o pairs --times 2,5,8

# 参考视频 vs 单张截图（游戏不便录时）
python skills\visual-taste\scripts\side_by_side.py 参考.mp4 shot.png -o pairs --times 5

# 数量化，别只靠眼睛
python skills\visual-taste\scripts\palette_report.py 参考.mp4 --json > 参考.json
python skills\visual-taste\scripts\palette_report.py shot.png  --json > 成品.json
```

## 三、看图时只回答四个问题

1. **缩略图大小下，这是同一个世界吗？**（不是：配色/光/雾错位）
2. **主体一眼能找到吗？**（不是：层次问题）
3. **哪里最"假"？**（通常是：天太干净、雾太薄、地面太平、细节均匀分布）
4. **这次只要改一项，改哪个收益最大？**

## 四、修改优先级（从小到大改）

1. **配色与分级**（改一处，全画面受益）—— 最常见的问题是饱和过高、暗部偏蓝、整体偏灰。
2. **雾与大气**（拉纵深、藏边界）—— 远处发灰、边缘露馅，都是雾的问题。
3. **光的方向与强弱**（影子对不对、主体有没有立体感）。
4. **密度与层次**（成组摆放，留空；不要均匀撒）。
5. **细节量**（贴图分辨率、道具数量）—— 最后做，因为最费时且收益最低。

## 五、拒收标准

出现任意一条，这张对比不算通过：

- 缩略图大小下能看出是两个世界（配色/气质不一致）；
- 主体小于画面高度 8%，或与背景亮度差 < 25 且饱和度差 < 0.15；
- 远近没有雾的层次，地平线直接切平；
- 画面里有文字/UI 抢注意力（除了最小标题与一行操作）；
- 与上一轮相比"感觉更好"但数字全在区间外——以数字出界为由重做，不以感觉为由放过。
